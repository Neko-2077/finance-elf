# 财报精灵 — AI 财务报表分析助手

> 7 位 AI Agent 组成的财务分析团队，独立桌面应用。无需 EasyClaw，双击即用。

---

## 🎯 这是什么

一个独立的桌面软件。上传财务报表 → 7 个 AI Agent 接力分析 → 输出完整财务分析报告。

**完全独立运行**，不依赖 EasyClaw，只依赖 DeepSeek API。

---

## 📥 安装 & 运行

### 方式一：直接下载

从 [Releases](../../releases) 下载安装包，双击安装。

### 方式二：源码运行

```bash
# 1. 安装依赖
npm install

# 2. 启动
npm start
```

---

## 🔑 配置 API Key

1. 打开软件
2. 左侧面板 → 填入 DeepSeek API Key
3. 获取 Key：https://platform.deepseek.com/api_keys

一个 Key 即可驱动全部 7 个 AI Agent。

## ⚙️ 三种分析模式

| 模式 | 流程 | 适用场景 |
|------|------|---------|
| 🔍 快速概览 | 解读官 → 风险预警员 | 快速了解财务状况，2-3分钟 |
| 📊 标准分析 | 解读官 → 研究员 → 分析师 → 审计顾问 | 常规财务分析报告 |
| 🏦 深度诊断 | 解读官 → 研究员 → 分析师 → 风险预警员 → 起草员 → 审计顾问 | 投资/尽调级深度分析 |

---

## 👥 团队角色

| 角色 | 职责 |
|------|------|
| 🔍 财报解读官 | 通读三张表，提取关键数据，标注异常项 |
| 📚 准则研究员 | 检索会计准则，判断会计政策合理性 |
| ⚖️ 比率分析师 | 偿债/盈利/营运/成长四维指标 + 杜邦分析 |
| 🔴 风险预警员 | 六大维度全面风险排查，分级预警 |
| ✍️ 报告起草员 | 将分析结果撰写成结构化报告 |
| 📋 审计顾问 | 终审验收，出具审计意见级别的结论 |

## 🛠 内核可修改

所有 Agent 的 System Prompt 在 `agents/` 目录下，直接编辑 `SOUL.md` 即可调整行为。

Pipeline 编排逻辑在 `pipeline-engine.js`，修改后重启即生效。

## 📖 输入格式

将财报数据整理为纯文本（.txt 或 .md），包含：

- **利润表**：营业收入、营业成本、各项费用、净利润
- **资产负债表**：资产、负债、所有者权益分项数据
- **现金流量表**：经营/投资/筹资三类现金流

示例格式见 `demo-finance.txt`。
